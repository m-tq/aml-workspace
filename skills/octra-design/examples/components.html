What is Synteq UI?
A viewport-locked, offline-first dashboard framework built on six hard rules, with a complete component library for operator dashboards and admin panels.
How do I get started?
Link synteq-ui.css and synteq-ui.js, then start from the shell template in the documentation.
Can I customize the theme?
Yes. Override the --sq-* custom properties in your own stylesheet — see the theme guide in DESIGN.md.
